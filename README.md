# C Programming - Logic Building Batch

## 📝 Description
This repository tracks my progressive journey in C Programming through the Logic Building batch. It contains daily classwork practice programs and structured assignment solutions. The codebase evolves from foundational programming concepts (loops, conditions, basic logic) to advanced problem-solving, complex logic building, pointers, and data structures.

**Author:** Abhishek Mahesh Khedkar

## 🚀 How to Compile and Run
All programs are written in standard C and can be compiled and executed using the GCC compiler via the terminal or command prompt.

1. **Open your terminal** and navigate to the specific folder (either a Classwork day or a specific Assignment):
   ```bash
   cd Classwork/Day_01
   # OR
   cd Assignments/Assignment_1
   ```

2. **Compile the C program** using gcc (replace filename.c with the actual file name):
   ```bash
   gcc filename.c -o outputname
   ```

3. **Run the generated executable:**
   * On Windows:
     ```bash
     .\outputname.exe
     ```
   * On Linux / Mac:
     ```bash
     ./outputname
     ```
